# Клёвое место — кооперативная рыбалка (v1.3.3, Godot 4.7.2)

## Запуск
**Готовая Windows-игра:** скачай архив Windows из [релиза v1.3.3](https://github.com/dbldkk/klevoe-mesto/releases/tag/v1.3.3),
распакуй и запусти `KlevoeMesto.exe`. Собирать части архива больше не нужно.
EXE распространяется через Releases; в Git хранятся исходники.
В Windows игра по умолчанию запускается в OpenGL. Если хочешь попробовать Vulkan, запусти `Play-Vulkan.bat`.

В главном меню есть «Как играть», а в меню паузы — «Памятка и достижения» с личными вехами и рекордом.
Мир сохраняется с резервной копией предыдущей записи (`.json.bak`). Если основной файл повреждён,
игра автоматически загрузит эту копию. При ошибке записи выход отменяется, чтобы можно было повторить сохранение.

Из редактора: F5 → в меню введи имя → «Создать мир» (или выбери мир и «Играть»).
Хост хранит мир у себя: всех игроков, их вещи, где они стояли, торговца и бутылки на земле.

## Кооп
- **На одном компьютере:** *Debug → Customize Run Instances…* → *Enable Multiple Instances* = 2.
  Каждая копия сама получит свой профиль. В одной — создай мир, во второй — «Подключиться» (127.0.0.1).
- **Локальная сеть:** IP хоста показан в меню паузы (Esc).
- **Интернет:** порт **7777 UDP** у хоста или Radmin VPN / ZeroTier. Позже — Steam.

## Управление
Внизу панель из 9 ячеек: что выбрано (1-9 или колесо мыши) — то в руках. **ЛКМ** — действие:
удочка — забросить/подсечь/тянуть, бутылка — выпить, еда — съесть, наживка — насадить, пустая бутылка — бросить.
ЛКМ с пустыми руками или битой — удар.
R — отпустить рыбу · B — сменить наживку · E — взять/говорить/платить/спрятаться/лечь спать/передать игроку ·
Q — колесо действий (обоссаться, обосраться, тост, фонарик, угостить, корзина, спор) ·
Tab — инвентарь · K — карта · V — камера · Пробел — прыжок/вылезти/встать · Y — принять спор ·
F11 — полный экран · F1 — подсказки. Все клавиши можно переназначить: Esc → Настройки → Управление.
В транспорте: W/S — газ/грести, A/D — руль, Пробел — звонок/гудок, E — выйти.

Внешность рыбака выбирается в главном меню (есть готовый образ «Друг из общаги»).
Чтобы F11 работал при запуске из редактора, во вкладке **Game** отключи *Embed Game on Next Play*.

## Механики
- **Ловля:** держи натяжение — рыба устанет. Перетянешь — износишь удочку или порвёшь леску.
  Заросли камыша — крупнее, но с зацепами. Глубина — судак и сом.
- **Ремонт удочек** — у Дяди Толи на рынке.
- **Алкоголь, туалет, голод** — шкалы слева внизу. Какашка — наживка для крупной рыбы.
- **Вода:** упал — плыви к пологому берегу или к лестнице у пирса.
- **«Шестёрочка», кража, охранник, торг с Дядей Толей** — как раньше. Охранника можно вырубить битой.
- **Посёлок:** дом с кроватью, «Бухло & Табак», казино, напёрстки, фандомат, подработка грузчиком, укрытия.
- **Рыбалка:** не подсекай, пока поплавок только «играет»; когда рыба рвётся в сторону — держи A/D против неё;
  выпрыгнула — отпусти ЛКМ.
- **Сон:** новый день — когда все легли в кровать дома; хост выбирает, до скольки спать; потом итоги дня.
- **Участковый Петрович:** ловит пьяных за рулём, воров и драчунов — «на сутки» в КПЗ (штраф 15%).
  Один — пропускаешь полдня, в коопе — 2 минуты за решёткой. Можно убежать или спрятаться в кустах.
- **Баба Зоя** на лавочке: черви, опарыш, семечки. Пьяных ругает и докладывает участковому.
- **Дом:** каталог на столе — ремонт, вторая кровать, холодильник (общий), телевизор (прогноз погоды).
- **Дальний плёс** за мостом на севере — глубоко, крупная рыба. Говорят, там живёт Царь-сом.
- **Сеть** (у бабы Зои): ЛКМ у воды — поставить, E — вытащить. Рыбнадзор на катере штрафует.
- **Участковый** поймал — можно попробовать договориться (деньги, рыба, бутылка).
- **Спор** (Z, глядя на игрока; Y — принять): переплыть озеро или выпить бутылку залпом.
- **Клуб «Огонёк»:** каждый третий день в 12:00 свадьба или поминки — бесплатно наливают, конкурсы, драка.
- **Подработки:** совхоз «Рассвет» (мешки, корова Зорька), ремонт «Нивы» у гаража.
- **Похмелье** утром — лечится рассолом (в холодильнике каждое утро).
- **Настройки** (Esc): графика, громкость по отдельности, клавиши, как говорят NPC (речь Windows / бормотание / текст).
  Для понятной речи нужен русский голос в Windows: Параметры → Время и язык → Речь → Добавить голоса.

## Где что лежит
```
data/                 параметры рыб, удочек, наживки, напитков (.tres)
scripts/autoload      сеть, сохранения, инвентарь, справочник, события, клавиши
scripts/player        игрок (выпивка, броски) и ловля
scripts/world         рельеф, вода, трава, заросли, бутылки, время суток, драки,
                      магазин (shop/), рынок (market/), постройки посёлка (places/), NPC (npc/)
scripts/art           модели людей, рыб, предметов
art/                  текстуры, лица, этикетки, значки
scripts/ui            HUD, инвентарь, торговец, казино, прилавок, передача, карта, итоги дня, пауза, меню
tools/                генераторы картинок и сцены мира (gen_world_scene.py)
```
Сохранения: `%APPDATA%\Game fish\worlds\`.
