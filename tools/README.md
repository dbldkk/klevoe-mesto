# Инструменты (Python 3 + Pillow + numpy)
- `gen_textures.py` — бесшовные текстуры в art/textures
- `gen_faces_labels.py` — лица, этикетки, вывески, значки
- `gen_world_scene.py` — генерирует scenes/world.tscn (магазин, рынок, пирс, полки)
- `lake_preview.py` — карта высот озера сверху (для настройки формы)
Пути внутри скриптов указывают на папку проекта — поправь под себя перед запуском.
